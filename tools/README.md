# tools/

Helpers for the repository's GitHub, CI and CodeRabbit work: reading check runs and review comments, judging a commit's gates, a guarded merge, and a CodeRabbit Verify read. The Worker never serves or uploads this folder: `wrangler.jsonc` sets `assets.directory` to `./web`, so nothing here reaches a visitor. Credentials are read by name, from the process environment, or on Windows the User environment; no value is written here. Reads on `Kolwen-AI/*` name `GITHUB_READ_TOKEN_KOLWEN_AI`: the org refuses the older read token by its lifetime rule (measured 2026-11-25), and the owner's new read token will move them back. Check-run reads (`/commits/<sha>/check-runs`) name `GITHUB_TOKEN`, GET only, because no fine-grained token reads check runs (main's rule, 2026-11-25). `GITHUB_TOKEN` also serves the writes (`kw-pr`, `kw-comment`, `kw-merge`'s merge, `cr-reply`, `rerequest`, the Verify press). `GITHUB_READ_TOKEN` stays accepted for the other repositories. The node tests run in CI (`tools/ciwait.test.mjs` is in the surface job); the PowerShell tests (`*.test.ps1`) run locally with Windows PowerShell 5.1 (`powershell -NoProfile -File tools/kw-merge.test.ps1`) and are not yet run in CI.
