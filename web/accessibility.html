Accessibility

This page is Kolwen's accessibility statement for the website at kolwen.com. It is dated 1 November 2026.

What this site is

Kolwen's website describes a chatbot product that is still in development. No product ships yet, and the home page says so. The site is a set of static pages in English and Thai, which a visitor reads in a browser.

Our commitment

Kolwen aims to make the website usable by people with disabilities, and to fix a problem that a visitor reports.

The standard we aim for

Kolwen's own target is WCAG 2.2 level AA. It is a target Kolwen set for itself. It is not a legal test, and this statement does not claim that the site meets it.

What is checked on every change

The repository runs these checks in its continuous integration on each pull request and each push to main, and a failed check fails the change. A headless browser checks every page, in English and Thai: text reflows at 320 CSS pixels wide without sideways scrolling; text at 200 percent is not cut off; the browser reports no content-security-policy violation; each language has its own address, and that address sets the page's language; the Thai text is drawn by the site's own Thai typeface; the skip link is the first stop when the keyboard starts and stays out of sight until it is focused; the header fits on at most two rows at 320 pixels and each of its links is inside the screen; each page names its own address and its alternate addresses; on the terms pages the section in view stays in view after the switch; and Tab reaches the skip link, the logo, Pricing and the link to the other language in that order, and Enter on that link opens the same page in the other language at its own address. On the reading pages, text and background meet a contrast of 4.5 to 1 (3 to 1 for large text) in both the light and the dark colour scheme, the line height is at least 1.5 times the font size, and the line length of English text is measured against 80 characters. The source checks confirm that the home page declares English as its language, and that the layout uses relative type sizes and a viewport setting that does not block zoom.

Known limits

The checks above cover only what they measure. They do not test every criterion of WCAG 2.2. In particular, the keyboard checks cover the header only (the skip link, the logo, Pricing and the link to the other language) and do not read the focus order or whether focus is visible anywhere else on the page; no check reads the names and roles of controls with a screen reader; the contrast and line-height checks cover the reading pages, not the default pages, whose background gradient is not read; the line-length check does not apply to Thai text; and the pages have not been checked with script switched off. The repository records no manual audit and no test with assistive technology by people.

What you need

The site needs a current browser. It needs no plug-in, and no account or sign-in to read a page. Whether a page reads with script switched off is not checked.

Report a problem

If a page is hard for you to use, write to info@kolwen.com with the address of the page and what got in your way. We read every report and answer it. We do not promise a time for the answer.

Date of this statement

1 November 2026.
