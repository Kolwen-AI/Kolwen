ผู้ประมวลผลช่วง

นี่คือผู้ให้บริการที่ประมวลผลข้อมูลส่วนบุคคลของลูกค้า Kolwen แทน Kolwen แต่ละรายทำหน้าที่อะไร ประมวลผลข้อมูลที่ใด ฐานการโอนข้อมูลไปต่างประเทศ และข้อตกลงการประมวลผลข้อมูลที่ใช้อยู่ Paddle ปรากฏในรายการเพื่อความโปร่งใส และทำหน้าที่เป็นผู้ควบคุมข้อมูลของตนเองสำหรับข้อมูลการซื้อ แต่ละแถวมีผลในวันที่ผู้ให้บริการของแถวนั้นเริ่มถือข้อมูลของลูกค้าเป็นครั้งแรก ก่อนถึงวันนั้น แถวจะระบุว่า จากวันที่เริ่มถือข้อมูลของลูกค้า

ผู้ให้บริการ

Cloudflare

วัตถุประสงค์

ให้บริการเว็บไซต์และบริการ ได้แก่ โฮสติ้ง Workers และพื้นที่จัดเก็บของ Workers และบันทึก

ข้อมูลส่วนบุคคล

คำขอที่ส่งเข้าเว็บไซต์ ตามที่ Cloudflare ประมวลผลเพื่อส่งหน้าเว็บ

สถานที่ประมวลผล

เครือข่ายของ Cloudflare และผู้ประมวลผลช่วงนอก EEA สวิตเซอร์แลนด์ และสหราชอาณาจักร ในประเทศที่ข้อตกลงไม่ได้ระบุ

ฐานการโอนข้อมูล

ข้อสัญญามาตรฐานของ EU (Module Two และ Module Three) ภาคผนวกสำหรับสหราชอาณาจักร ภาคผนวกสำหรับสวิตเซอร์แลนด์ และกรอบความเป็นส่วนตัวข้อมูล EU-U.S. ในกรณีที่ Cloudflare ได้รับการรับรองภายใต้กรอบนี้

ระยะเวลาการเก็บ

เก็บไว้จนสิ้นสุดข้อตกลงหลักหรือจนกว่าการประมวลผลจะไม่จำเป็นอีก หลังจากนั้น Cloudflare ลบหรือส่งคืนข้อมูลตามที่ลูกค้าเลือก เว้นแต่กฎหมายกำหนดให้เก็บไว้ ข้อตกลงไม่ได้ระบุจำนวนวันที่แน่นอน Workers Logs (บันทึกของ Worker เอง) เก็บไว้ 3 วันในแพ็กเกจ Workers ที่ Kolwen ใช้อยู่ในขณะนี้ และ 7 วันในแพ็กเกจ Workers แบบชำระเงิน จนถึง 30 พฤศจิกายน 2569 ตามหน้าราคา Workers ของ Cloudflare อ่านเมื่อ 8 พฤศจิกายน 2569; ตั้งแต่ 1 ธันวาคม 2569 Workers Logs จะใช้การคิดราคาแบบ Cloudflare Observability ส่วนระยะเวลาเก็บหลังวันนั้นไม่ได้ระบุไว้ที่นี่

ข้อตกลงการประมวลผลข้อมูล

ข้อตกลงการประมวลผลข้อมูลของลูกค้า ฉบับที่ 6.4 มีผลตั้งแต่ 3 เมษายน 2569

ผู้ให้บริการ

Supabase

วัตถุประสงค์

การเข้าสู่ระบบบัญชี และฐานข้อมูลของบริการ

ข้อมูลส่วนบุคคล

ตัวตนของบัญชี (ชื่อและที่อยู่อีเมล) และค่าแฮชของรหัสผ่าน

สถานที่ประมวลผล

ภูมิภาคของโปรเจกต์ ซึ่งเลือกเมื่อสร้างบัญชี จากภูมิภาคที่ Supabase ระบุไว้ ฐานข้อมูลและการเข้าสู่ระบบของโปรเจกต์โฮสต์อยู่ในภูมิภาคนั้น ข้อตกลงของ Supabase ระบุว่าข้อมูลที่อยู่ภายใต้ข้อตกลงอาจถูกประมวลผลได้ทุกที่ที่ Supabase หรือผู้ประมวลผลช่วงมีสถานที่ตั้ง และข้อผูกพันเรื่องภูมิภาคจะไม่บังคับเมื่อกฎหมายหรือบริการที่ลูกค้าขอต้องการ ข้อมูลบัญชีและข้อมูลการสนับสนุนเป็นข้อมูลที่อยู่ภายใต้กฎนี้ การวัดผลของบริการถูกส่งไปยังระบบที่แยกจากโปรเจกต์ของลูกค้า และข้อตกลงไม่ได้ระบุภูมิภาคสำหรับข้อมูลนั้น

ฐานการโอนข้อมูล

ข้อสัญญามาตรฐานของ EU (Module Two และ Module Three) พร้อมภาคผนวกสำหรับสหราชอาณาจักรและสวิตเซอร์แลนด์ ในกรณีที่ข้อมูลออกนอก EEA สหราชอาณาจักร หรือสวิตเซอร์แลนด์

ระยะเวลาการเก็บ

ลูกค้าขอสำเนาได้ภายใน 30 วันหลังข้อตกลงสิ้นสุด หลังจากนั้นข้อมูลจะถูกลบ รวมถึงสำเนาที่ผู้ประมวลผลช่วงเก็บไว้ ข้อตกลงไม่ได้ระบุจำนวนวันสำหรับการลบให้เสร็จ

ข้อตกลงการประมวลผลข้อมูล

ข้อตกลงการประมวลผลข้อมูล ฉบับที่ 1 (1 สิงหาคม 2569) ซึ่งต้องยอมรับก่อนบัญชีถือข้อมูลของลูกค้า

ผู้ให้บริการ

Paddle

วัตถุประสงค์

ผู้ขายตามบันทึกสำหรับการซื้อ ได้แก่ การชำระเงินและภาษี Paddle ทำหน้าที่เป็นผู้ควบคุมข้อมูลของตนเองสำหรับข้อมูลการซื้อ

ข้อมูลส่วนบุคคล

ชื่อ ที่อยู่อีเมล และข้อมูลการชำระเงินและภาษีของผู้ซื้อ

สถานที่ประมวลผล

นิติบุคคลผู้ควบคุมของ Paddle ในสหราชอาณาจักร สหรัฐอเมริกา ไอร์แลนด์ และแคนาดา และผู้ประมวลผลของ Paddle ในที่ใดก็ได้ในโลก

ฐานการโอนข้อมูล

ข้อสัญญามาตรฐานของ EU (Module One ผู้ควบคุมถึงผู้ควบคุม) และ UK Approved Addendum สำหรับการโอนจากสหราชอาณาจักรหรือ EEA ไปยังประเทศที่ไม่มีการตัดสินว่าเพียงพอ

ระยะเวลาการเก็บ

ไม่มีระยะเวลาคงที่ เก็บไว้ตลอดเวลาที่ความสัมพันธ์กับลูกค้ายังดำเนินอยู่ หรือตามที่กฎหมายกำหนด และตลอดอายุความและช่วงเวลาดำเนินการทางธุรการที่สั้นหลังจากนั้น เก็บไว้ด้วยในขณะที่มีข้อเรียกร้อง การสอบสวน หรือข้อพิพาทค้างอยู่

ข้อตกลงการประมวลผลข้อมูล

ไม่มีในฐานะผู้ประมวลผล: Paddle ทำหน้าที่เป็นผู้ควบคุมของตนเองภายใต้ Data Sharing Addendum
